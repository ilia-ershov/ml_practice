# Clustering

This folder contains my machine-learning practice focused on **unsupervised
learning and clustering** with Python and Jupyter notebooks.

## Contents

| File | Description |
| --- | --- |
| `task.ipynb` | Original clustering assignment |
| `solution.ipynb` | K-Means implementation, synthetic data experiments, and airline-customer analysis |
| `creative.ipynb` | Weather-based location clustering project |
| `map.html` | Interactive map generated by `creative.ipynb` |

## What I did

### K-Means from scratch

In `solution.ipynb`, I implemented the main steps of K-Means instead of using
only a library implementation:

- generated synthetic data with five known groups;
- standardized the features;
- implemented Euclidean distance with NumPy;
- assigned points to their nearest centroid;
- recalculated centroids iteratively;
- handled empty clusters by preserving the previous centroid;
- visualized the resulting clusters and centroids;
- experimented with probability-based centroid initialization.

### Airline customer clustering

I applied clustering to airline passenger data by:

- selecting numerical features;
- filling missing arrival-delay values using departure-delay values;
- combining related service variables into broader satisfaction features;
- examining feature correlations;
- standardizing and scaling the data;
- comparing inertia for different values of `k`;
- fitting K-Means with three clusters;
- comparing the average characteristics of each cluster with the overall
  average passenger.

### Weather location clustering

In `creative.ipynb`, I used weather data to group locations with similar
conditions. The workflow includes:

- removing unnecessary time, duplicate-unit, and metadata columns;
- combining related measurements into air-quality, temperature, and wind
  features;
- aggregating observations by location;
- calculating location-level summary statistics;
- standardizing the features;
- comparing candidate cluster counts using inertia;
- fitting a six-cluster K-Means model;
- displaying the locations on an interactive Folium map.

## Conclusions

The work showed that preprocessing has a major effect on clustering results.
Standardization is necessary because features with larger numerical ranges can
otherwise dominate Euclidean distance calculations.

Feature engineering also changes the meaning of the resulting clusters.
Combining related variables makes the groups easier to interpret, but the
chosen features determine which characteristics receive the most importance.

The airline analysis identifies passenger groups with different combinations
of travel characteristics, service ratings, and delays. These clusters can be
used as exploratory customer segments, but they should not be treated as
definitive categories without additional validation.

The weather analysis groups locations with similar temperature, wind,
visibility, precipitation, humidity, and air-quality patterns. The map provides
a useful geographic view of these groups and makes the results easier to
interpret.

Finally, the number of clusters should not be selected from inertia alone.
The elbow method is useful for exploration, but silhouette scores, cluster
stability, and domain knowledge should also be considered. K-Means is most
appropriate for relatively compact, separated clusters and may be less
effective for irregularly shaped groups or data with strong outliers.

## Installation

The notebooks use Python and Jupyter. Python 3.10 or newer is recommended.

From the repository root:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

On Windows, activate the environment with:

```powershell
.venv\Scripts\activate
```

Install the required packages:

```bash
python -m pip install --upgrade pip
python -m pip install jupyter numpy pandas matplotlib seaborn scikit-learn folium
```

## Required datasets

The notebooks expect these CSV files in the `clustering/` folder:

```text
clustering/airline.csv
clustering/GlobalWeatherRepository.csv
```

The datasets are not included in this repository. Download the corresponding
files separately and keep these filenames and paths unchanged.

## Running the notebooks

Start Jupyter from the repository root:

```bash
jupyter notebook
```

Open one of the following notebooks:

- `clustering/solution.ipynb`
- `clustering/creative.ipynb`

Run the cells from top to bottom. The cells that load CSV files require the
datasets described above.

After running the map-generation cells in `creative.ipynb`, open
`clustering/map.html` in a web browser to view the interactive result.
