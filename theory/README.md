# Theory

Written solutions to the math and ML-fundamentals assignments that accompany the
practical projects in this repository. Most solutions are typeset in LaTeX;
the `.pdf` next to each `.tex` file is the compiled version.

## Contents

### [Linear algebra](linear-algebra/) — assignments 1–5

| Assignment | Topics | Files |
| --- | --- | --- |
| 1. Vectors | Linear combinations, norms ($\ell_1$, $\ell_2$), angles, Gaussian elimination | `solution1.tex` / `.pdf` |
| 2. Matrices | Matrix operations, determinants, inverses, matrix equations, $\mathrm{Tr}(AB - BA) = 0$ | `solution2.tex` / `.pdf` |
| 3. Linear spaces | Linear independence, bases, rank, eigenvalues and eigenvectors | `solution3.tex` / `.pdf` |
| 4. Linear operators | Operator matrices, quadratic forms, Gram–Schmidt orthogonalization | `solution4.tex` / `.pdf` |
| 5. SVD and tensors | Singular value decomposition, pseudoinverse, tensors and contraction | `solution5.tex` / `.pdf` |

The individual solutions are written in Russian.
**[`all_solutions_en.pdf`](linear-algebra/all_solutions_en.pdf)** is a full
English translation of all five assignments in one document.

### [Calculus](calculus/) — limits and derivatives

- `assignment.pdf` — problem set: limits, derivatives from the definition,
  secant and tangent slopes, velocity as a derivative, reading a graph of $f'(x)$.
- `solution.pdf` — handwritten solutions.

### [ML basics](ml-basics/) — introductory ML questions

- `assignment.pdf` — problem set.
- `solution.tex` / `solution.pdf` — feature types (categorical, ordinal,
  quantitative), formulating real-world problems as ML tasks (objects, target,
  task type), and general ML questions.

> The calculus and ML-basics materials are in Russian.
